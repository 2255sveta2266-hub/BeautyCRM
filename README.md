# BeautyCRM

BeautyCRM — небольшой веб-проект для управления салоном красоты. Он разрабатывается в рамках лабораторных работ по дисциплине «Интернет-программирование».

## О проекте

Сайт предназначен для администратора салона. С его помощью можно работать с клиентами, мастерами, услугами и записями. Также на главной странице есть календарь и блоки с основной информацией о работе салона.

Проект пока сделан на HTML, CSS и JavaScript. В дальнейшем его можно будет расширять и добавлять новые возможности.

## Что умеет сайт

На данный момент в проекте реализованы:

- Просмотр списка клиентов, мастеров, услуг и записей.
- Добавление новых данных, их редактирование и удаление.
- Поиск по спискам и фильтрация записей по статусу.
- Сортировка записей по дате.
- Изменение статуса записи.
- Отметка VIP-клиентов.
- Просмотр подробной информации в отдельном окне.
- Календарь с записями на выбранные дни.
- Просмотр финансовых показателей и статистики по услугам.
- Поиск клиента при создании записи.
- Сохранение данных в браузере с помощью localStorage.

В проекте уже добавлены 6 услуг и 4 мастера. Клиентов и записи можно добавлять самостоятельно через интерфейс сайта.

## Используемые технологии

- HTML5 — структура страницы.
- CSS3 — оформление и адаптация под разные размеры экрана.
- JavaScript — работа с данными и интерактивными элементами.
- localStorage — сохранение информации в браузере.
- Git и GitHub — хранение и отслеживание изменений проекта.

## Как запустить

Для запуска не требуется устанавливать дополнительные программы или настраивать сервер.

1. Скачать проект или клонировать репозиторий.
2. Открыть папку проекта.
3. Запустить файл `index.html` в браузере.

Некоторые шрифты загружаются из Google Fonts, поэтому для их отображения нужен интернет.
