# BeautyCRM

BeautyCRM — учебный проект для салона красоты. Здесь можно вести список клиентов, мастеров и услуг, записывать клиентов на приём и смотреть календарь и выручку.

Проект начинался с HTML, CSS и JavaScript (ЛР №1). Потом я перенесла интерфейс на React и TypeScript (ЛР №2) и добавила сервер на NestJS (ЛР №3).

## Как запустить ЛР №3

Понадобится Node.js 22. Откройте папку проекта в VS Code и создайте два терминала PowerShell.

В первом терминале запустите сервер:

```powershell
cd backend
npm.cmd ci
npm.cmd run start:dev
```

Во втором терминале, в папке с основным `package.json`, запустите сайт:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте [BeautyCRM](http://localhost:5173/BeautyCRM/). Оба терминала оставьте открытыми. Команда `npm.cmd ci` нужна для установки зависимостей, при обычном повторном запуске её можно пропустить.

Для проверки API откройте [Swagger](http://localhost:3000/api/docs). Данные NestJS хранятся в памяти и сбрасываются при перезапуске. Чтобы проверить создание записи, сначала добавьте клиента, мастера и услугу.

## Как запустить ЛР №2

Установите зависимости командой `npm.cmd ci` в корне проекта. В первом терминале запустите JSON Server:

```powershell
npm.cmd run api
```

Во втором терминале из корня проекта запустите сайт с адресом учебного API:

```powershell
$env:VITE_API_URL = 'http://localhost:3001'
npm.cmd run dev
```

Откройте [BeautyCRM](http://localhost:5173/BeautyCRM/). Изменения в этом режиме сохраняются в `db.json`. Для возврата к NestJS остановите Vite, выполните `Remove-Item Env:VITE_API_URL` и снова запустите Vite.

## Что есть в проекте

- Отдельные экраны записей, клиентов, мастеров, услуг, финансов и аналитики. Из списка клиентов можно открыть карточку по адресу `#/clients/:id`.
- В записях есть поиск, фильтр по статусу и сортировка. В календаре можно выбрать день и посмотреть его записи.
- Сервер поддерживает просмотр, добавление, редактирование и удаление клиентов, мастеров, услуг и записей. Входные данные проверяются на сервере.

Код интерфейса лежит в `src/`, код сервера — в `backend/src/`. На GitHub Pages размещён интерфейс. Для работы с данными запустите проект локально.
