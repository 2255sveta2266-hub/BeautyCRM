# BeautyCRM: лабораторная №2

Полный проект на React + TypeScript, React Router, REST API через JSON Server. Оригинальное оформление первой лабораторной сохранено в `src/App.css`.

## Установка (Windows, PowerShell)

1. Распакуй архив в отдельную папку `BeautyCRM_Lab2_ready` (старый проект можно оставить нетронутым).
2. Открой эту папку в VS Code.
3. Выполни `npm.cmd install` один раз.
4. Запусти **два терминала**:
   - `npm.cmd run dev` (сайт `http://localhost:5173`)
   - `npm.cmd run api` (API `http://localhost:3001`)
5. Открой сайт в браузере.

**Важно:** не запускай одновременно старую копию проекта на портах 5173/3001. Если они заняты, останови старые процессы через Ctrl+C.

## Что работает

- Главная и отдельные экраны записей, клиентов, мастеров, услуг, финансов и аналитики.
- Нижняя панель: «Новая запись», «Добавить клиента», «Добавить услугу» открывают формы; «Аналитика» открывает экран аналитики.
- Единое модальное окно в исходном стиле первой лабораторной.
- Клиенты, мастера, услуги, записи: добавление, изменение, удаление.
- Сохранение в `db.json` через GET/POST/PATCH/DELETE.
- Поиск клиентов и записей, фильтр и сортировка записей, смена статуса.
- Календарь, статистика, финансы, аналитика.
- Маршруты `/`, `/appointments`, `/clients`, `/clients/:id`, `/masters`, `/services`, `/finances`, `/analytics`. В адресе после имени сайта стоит `#`, чтобы прямые ссылки работали на GitHub Pages.
- Пустая база без чужих мастеров и услуг.

## Примечание

JSON Server используется для учебного REST API. Это **не** многопользовательский production backend: здесь пока нет авторизации, разделения данных салонов и серверной проверки доступа. Реальные персональные данные клиентов не вводи.
