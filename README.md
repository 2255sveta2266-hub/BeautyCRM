# BeautyCRM

Клиентская часть CRM-системы для салона красоты (лабораторная работа №1, «Интернет-программирование»).

## Описание проекта

**Назначение.** Администратор салона ведёт клиентов, услуги, мастеров и расписание записей в одном окне вместо бумажного журнала и мессенджеров.

**Пользователи.** Администратор салона (в следующих работах — также мастера и клиенты).

**Основные сущности** (в дальнейшем — таблицы PostgreSQL):
- **Клиент** — имя, телефон, email, VIP-отметка;
- **Услуга** — название, стоимость, длительность;
- **Мастер** — имя, специализация;
- **Запись** — клиент, услуга, мастер, дата, время, статус, комментарий.

**Действия пользователя:** просмотр, поиск, фильтрация, сортировка, создание, редактирование, удаление, просмотр подробной информации.

## Запуск

Сервер не нужен: откройте `index.html` в браузере (двойной клик).
Для шрифтов Google Fonts нужен интернет; без него подставятся Georgia и Segoe UI.

## Структура проекта

```
index.html   — разметка страницы
style.css    — стили, Flexbox/Grid, медиазапросы
script.js    — данные, отрисовка, формы, события
README.md
```

## Реализованные возможности

- Семантическая вёрстка: `aside`, `nav`, `header`, `main`, `section`, `article`.
- Данные хранятся в массивах объектов JavaScript (клиенты, услуги, мастера, записи). Начальные данные (6 услуг и 4 мастера) заданы в `script.js` в функции `createStartData()`, остальное добавляется через формы на сайте.
- Таблица записей: **поиск**, **фильтр по статусу**, **сортировка по дате**.
- Создание, **редактирование** и **удаление** клиентов, услуг, мастеров и записей (если у объекта есть записи, удалить его нельзя).
- **Смена статуса** записи кликом, **VIP-звёздочка** у клиентов.
- В форме записи есть **поиск клиента**: список выбора фильтруется по мере ввода имени.
- **Карточки с подробностями** (клиент, услуга, мастер, запись) в модальном окне.
- **Календарь** с отметками дней, где есть записи, и списком записей на выбранный день.
- **Финансы** (выручка, ожидаемая выручка, средний чек) и **аналитика** (круговая диаграмма популярных услуг).
- Формы добавления с проверкой: HTML-атрибуты (`required`, `min`, `max`, `minlength`) и JavaScript
  (формат имени и телефона, рабочие часы, запрет записи в прошлое, занятость мастера, дубли).
- Сохранение данных в `localStorage` (после перезагрузки страницы данные остаются).
- Адаптивная вёрстка (ПК, планшет, телефон), состояния `hover` и `focus`.
